# bakery_dagster

The Dagster project and Streamlit dashboard for the bakery sales pipeline. See the [main README](../README.md) for an overview, screenshots and setup steps.

Quick start, from this folder:

```bash
uv sync
uv run dg dev                              # pipeline UI at http://localhost:3000
uv run streamlit run dashboard/app.py      # dashboard at http://localhost:8501
```
